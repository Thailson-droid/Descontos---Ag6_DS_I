# Calculadora de Descontos 🧾
 
Programa em Python que calcula o valor final de uma compra aplicando descontos conforme o valor informado.
 
## Regras de desconto
 
- Compras abaixo de R\( 200: desconto de 5\%
- Compras entre R\) 200 e menos de R\( 300: desconto de 10\%
- Compras a partir de R\) 300: desconto de 15%
 
## Tecnologias utilizadas
 
- Python
- Estruturas condicionais: `if`, `elif` e `else`
